# Conversión de AFN-ε a AFD — Versión con Interfaz Gráfica

Programa con **interfaz gráfica (Tkinter)** para convertir un Autómata Finito No Determinista con transiciones vacías (AFN-ε) en un Autómata Finito Determinista (AFD).

---

## Características

- Interfaz gráfica moderna y fácil de usar
- 3 ejemplos pre-cargados con un solo clic
- Captura de estados, alfabeto, inicial, finales y transiciones
- Visualización de todas las tablas de transición
- Validación de cadenas con recorrido de estados


## Uso

1. Haz clic en uno de los **ejemplos** o escribe tu propio AFN-ε
2. Presiona **Convertir AFN-ε → AFD**
3. Revisa las tablas en la pestaña **Tablas de transición**
4. Prueba cadenas en la pestaña **Validar cadenas**
5. Genera el diagrama en la pestaña **Diagrama Graphviz**
